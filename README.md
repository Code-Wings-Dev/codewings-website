# CodeWings Website

A responsive, animated static marketing website for CodeWings, built with HTML, CSS, and vanilla JavaScript.

## Run locally

1. Extract the project folder.
2. Open `index.html` in a modern browser, or run a local static server from this folder (for example `python -m http.server 8000`).
3. Visit `http://localhost:8000`.

## Included

- Responsive desktop, tablet, and mobile layouts
- Mobile navigation menu
- Scroll reveal animations and reading progress bar
- Reduced-motion accessibility support
- Services, company overview, process, capabilities, and contact sections
- Contact form that prepares an email addressed to `info@code-wings.com`
- Provided CodeWings logo asset

## Before launch

- Confirm the contact email, office address, and public LinkedIn URL.
- Replace/add real project case studies and approved screenshots when available.
- If you need inquiries to be submitted directly from the site, connect the form to a backend or form provider; the current form opens the visitor's email application and does not store submissions.
- Configure hosting, HTTPS, analytics (if wanted), and a production domain.
